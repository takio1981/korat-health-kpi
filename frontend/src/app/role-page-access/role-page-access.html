สิทธิ์การเข้าถึงหน้า

เปิด/ปิดการเข้าถึงแต่ละหน้าของระบบ แยกตาม Role — Super Admin เข้าได้ทุกหน้าเสมอ ไม่แสดงในตาราง

ติ๊กช่อง = Role นั้นเห็นเมนูและเข้าหน้านั้นได้ (ทั้งฝั่งหน้าเว็บและสิทธิ์เรียก API จริง ไม่ใช่แค่ซ่อน/แสดงเมนู)

Super Admin เข้าได้ทุกหน้าเสมอ ไม่สามารถปิดได้ (กันตั้งค่าผิดพลาดจนเข้าระบบไม่ได้)

ข้อจำกัดสำคัญ: หน้า "จัดการตัวชี้วัด" เมื่อเปิดให้ Role อื่น จะปลดล็อคเฉพาะฟีเจอร์ "เพิ่มตัวชี้วัดจำนวนมาก" เท่านั้น — การแก้ไข/ลบตัวชี้วัด/หมวดหมู่/หน่วยงาน/หน่วยบริการ และ Form Builder ยังคงจำกัดเฉพาะ Super Admin เหมือนเดิมเสมอ

หน้า "จัดการผู้ใช้งาน" เมื่อเปิดให้ Role อื่น จะปลดล็อคการดู/เพิ่ม/แก้ไข/ลบ/รีเซ็ตรหัสผ่านผู้ใช้งานทั่วไป — ส่วนอนุมัติ/ตีกลับผู้ใช้ใหม่, ตั้งค่าสิทธิ์แก้ไขข้อมูล, และ sync ข้อมูลไป HDC ยังคงจำกัดเฉพาะที่กำหนดไว้เดิม (admin_ssj/super_admin หรือ super_admin เท่านั้นตามแต่ละฟีเจอร์)
